## How to report

1. Open the **[Issues](../../issues)** tab and click **New issue**.
2. Choose **Bug report** or **Suggestion** and fill in the form.
3. Search existing issues first — your problem may already be reported.

You can write in **English or Spanish** (también puedes escribir en español).

Need help with setup instead? Check the wiki or open a ticket on our **[Discord](https://discord.gg/GzxW2FANPB)**.

---

The plugins are closed source. This repository only contains the issue tracker.
